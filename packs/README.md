# Compendium Packs

Compendium packs in Foundry v12 use **LevelDB** directories (not the older NeDB `.db` files). Each pack is a folder under `packs/<pack-id>/` containing many small files, generated by Foundry when you click **Export to Compendium** on a folder in your World.

## Scaffolding

The system is configured (in `system.json`) to discover packs at runtime. Add a pack by:

1. In a World running this system, create a Compendium (Compendium Packs > Create New Compendium).
2. Build out the entries (e.g., the default Skills, Knacks, Schools, Sorceries — see `lang/en.json` for canonical names).
3. Export and copy the resulting `packs/<pack-id>/` folder into this directory.
4. Add an entry to `system.json` like:

   ```json
   "packs": [
     {
       "name": "ss1e-skills",
       "label": "7th Sea Skills",
       "system": "seventh-sea-1e",
       "path": "packs/ss1e-skills",
       "type": "Item",
       "ownership": { "PLAYER": "OBSERVER", "ASSISTANT": "OWNER" }
     }
   ]
   ```

## Suggested starter packs

- `ss1e-skills` — Item, full default skill list from the 1e Player's Guide.
- `ss1e-knacks` — Item, every basic + advanced knack pre-built.
- `ss1e-schools` — Item, the major Swordsman Schools (Andrews, Ambrogia, Aldana, Boucher, Donovan, Eisenfaust, …).
- `ss1e-sorceries` — Item, the ten major sorceries.
- `ss1e-advantages` — Item, common advantages from the corebook.
- `ss1e-bestiary` — Actor, sample monsters and Brute Squads.

The Foundry CLI can also build LevelDB packs from JSON source:

```bash
npm install -g @foundryvtt/foundryvtt-cli
fvtt package pack -n "ss1e-skills" --type "System" --id "seventh-sea-1e" \
  --in "src/skills" --out "packs/ss1e-skills"
```
